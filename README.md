# КЦ «ЗИМ Галерея»: мини-лендинг аренды пространства

Статичный сайт на три экрана: HTML + CSS + JS, без сборки и внешних библиотек. Открывается двойным щелчком по `index.html` (для file:// шрифты встроены в `assets/css/fonts-local.css`). Заливать на хостинг нужно содержимое этой папки `site`. КП с ценами лежит уровнем выше и на сайт попасть не должен.

| Экран | Что на нём |
|---|---|
| 1. Оффер | Лекторий и выставочный зал в аренду, кнопка «Узнать условия», цифры: площадь, вместимость, адрес |
| 2. Пространство | Форматы событий, преимущества из КП, фото лектория, лестницы, зоны отдыха, выставочного зала (на телефоне листаются свайпом) |
| 3. Заявка | Что входит в аренду, инфраструктура, услуги по запросу, форма |

Контент взят из `../КП ЗИМ от 10. 2026.pdf`, цены намеренно не используются. Фото из папки крео `аренда`.

## Перед запуском

1. **Обработчик заявок.** В начале `assets/js/main.js`, объект `CONFIG`: задать `FORM_ENDPOINT` (CRM или вебхук). Пока он пуст, заявка никуда не уходит, хотя посетитель видит «Заявка принята».
2. **Метрика.** Там же `YM_COUNTER` и добавить код счётчика в `index.html`. Цель: `rent_lead`, событие в `dataLayer` то же.
3. **Индексация.** Убрать `<meta name="robots" content="noindex, nofollow">` из `index.html`.

## Настройка

- В заявку уходят: `name`, `phone`, `event_format`, согласия, `utm_*`, `offer`, `page`, `submitted_at`.
- Быстрые ссылки Директа ведут на готовые якоря: `#форматы`, `#фото`, `#форма`, `#карта`.
- Согласия и ссылки на документы те же, что на лендинге экскурсии (`catalog.zim-galereya.ru`).
- При смене `main.css` или `main.js` обновляйте метку `?v=` в `index.html`.
- Всё движение отключается при `prefers-reduced-motion`.
